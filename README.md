# 🏛️ AetherVault
**The Future of Decentralized Digital Legacy & Intellectual Property**

AetherVault is an end-to-end encrypted protocol on BNB Chain, providing a permanent, trustless registry for digital assets and intellectual property. We bridge high-frequency blockchain interaction with perpetual decentralized storage to secure your digital footprint forever.

## 🚀 Live Demo
Access the AetherVault dApp here: [https://aethvault.xyz](https://aethvault.xyz)

## 💎 Core Pillars
*   **Aether Capsule:** Military-grade ECIES-encrypted time-capsule storage.
*   **Legacy Vault:** Autonomous "Dead-man's Switch" for secure digital inheritance.
*   **Aether Proof™:** On-chain NFT registry for IP ownership and verification.
*   **Perpetual Data:** Powered by **Irys & Arweave** for permanent file persistence.
