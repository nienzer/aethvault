## 🧪 Accelerated Testing Parameters Disclosure
To facilitate rapid and efficient auditing/testing on the BNB Chain Testnet, several time-dependent smart contract parameters have been configured to **accelerated durations**[cite: 9]. These are intended solely for testing purposes and will be updated to their production-grade counterparts before Mainnet deployment[cite: 9].

The following components utilize these accelerated test settings:

1.  **Aether Capsule & Legacy Vault (Dead-man's Switch):**[cite: 9]
    *   *Production Intent:* Multi-year/Multi-month inactivity triggers[cite: 9].
    *   *Testnet Config:* Accelerated to minute-based triggers for verification of state changes[cite: 9].

2.  **AetherVaultStaking (Timelock Governance):**[cite: 9]
    *   *Production Intent:* 48-hour delay for parameter updates[cite: 9].
    *   *Testnet Config:* Reduced duration to allow immediate verification of governance flow[cite: 9].

3.  **TeamVesting (Cliff & Linear Release):**[cite: 9]
    *   *Production Intent:* 6-month cliff and 24-month linear vesting[cite: 9].
    *   *Testnet Config:* Scaled down to allow full verification of the vesting lifecycle within a single testing session[cite: 9].

4.  **veAETH & AetherGovernor (DAO Governance):**
    *   *Production Intent:* Standard multi-day voting periods and strict proposal thresholds.
    *   *Testnet Config:* Optimized voting and proposal parameters for rapid community testing and validation.

*All time-lock variables are hard-coded in the source contracts as modular constants, allowing for seamless transition to production parameters without requiring logic re-writes.*[cite: 9]
